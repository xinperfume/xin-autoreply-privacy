Xin AutoReply — Privacy Policy

Last updated: November 9, 2026 · 繁體中文版在下方

Xin AutoReply is a private tool used only by the owner of the Threads account @xinnnnnn88 to manage that account's own activity on Threads. It is not offered to any other user.

What data the app uses

  • The owner's own Threads profile (ID and username), to make API requests on the owner's behalf.
  • Recent public Threads posts that contain recommendation-request keywords (for example "求推薦"), returned by the Threads keyword search API: post ID, text, username, time and link.
  • The text of replies under those posts, only to count whether shopping links were already posted.

How the data is used

  • To decide whether a post is asking for a product recommendation, and to draft a short helpful reply.
  • Post text may be sent to Google's Gemini API to classify the post and draft the reply. No other third party receives the data.
  • Every reply is reviewed by, or reported to, the account owner. Replies are limited to at most 10 per day and one per account.

What is stored and for how long

  • IDs of posts already processed, kept for up to 45 days to avoid processing the same post twice.
  • Usernames that were already replied to, so the same person is not contacted again.
  • Data is stored in a private repository accessible only to the owner. It is never sold, shared, or used for advertising.

Data deletion

To have any data about your Threads account removed, email xxinperfume@gmail.com with your Threads username. All records of your username and posts will be deleted within 7 days, and you will be added to a do-not-reply list.

Contact

xxinperfume@gmail.com

隱私權政策（繁體中文）

Xin AutoReply 是 Threads 帳號 @xinnnnnn88 的擁有者自己使用的工具，用來管理自己帳號在 Threads 上的活動，不提供給其他人使用。

  • 使用的資料：擁有者自己的帳號資料；Threads 關鍵字搜尋 API 回傳的公開貼文（貼文編號、內容、帳號名稱、時間、連結）；這些貼文底下的留言內容（只用來計算是否已有購物連結）。
  • 用途：判斷貼文是否在詢問商品推薦，並擬一則簡短的建議回覆。貼文內容可能會送到 Google Gemini API 協助判斷與擬稿，不會提供給其他第三方。每天最多回覆 10 則，同一個帳號只回一次。
  • 保存：處理過的貼文編號最多保存 45 天；已回覆過的帳號名稱會保存，以免重複打擾。資料存放在只有擁有者能存取的私人空間，不會販售、分享或用於廣告。
  • 刪除資料：寄信到 xxinperfume@gmail.com 並附上你的 Threads 帳號名稱，我們會在 7 天內刪除所有相關紀錄，並把你加入不再回覆的名單。
